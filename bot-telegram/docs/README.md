# 📚 docs/ — Documentación

Índice de la documentación del proyecto.

| Documento | Contenido |
|-----------|-----------|
| [`../README.md`](../README.md) | Visión general, cómo funciona, puesta en marcha, índice de carpetas. |
| [`arquitectura.md`](arquitectura.md) | Arquitectura actual y objetivo (microservicios), diagramas y reglas. |
| [`roadmap.md`](roadmap.md) | Mejoras futuras: refactor, código limpio, microservicios, tests, seguridad. |
| [`../routes/README.md`](../routes/README.md) | Índice de rutas/puntos de entrada y a qué servicio van. |

## Cómo mantenerla
- Cada carpeta nueva debe traer su `README.md`.
- Cada ruta/comando nuevo se agrega en `routes/README.md`.
- Cada cambio de arquitectura se refleja en `arquitectura.md`.
- Las mejoras pendientes se marcan en `roadmap.md`.
